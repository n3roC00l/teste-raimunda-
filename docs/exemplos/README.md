# Exemplos

- **`programacao-semeadora-exemplo.xlsx`** — planilha de programação da semeadora
  passada pelo Leandro (ensaio "Antecipado Pinhão 2025"), fonte da nomenclatura.
  - Aba `Plan1`: 1 linha por plot (216), colunas `Parcela Larg. (X)` 1…12,
    `Parcela Compr.(Y)` 1…18, `ID Opcional` (nome do experimento),
    `Carreiras por parcela` = 3, e colunas vazias `linha 1` / `linha 2` / `linha 3`
    (onde entra a contagem no export).
  - Aba `Planilha1`: grade visual — confirma o identificador do plot: **`X{n}Y{m}`**.
- **`programacao-semeadora-exemplo.csv`** — mesma aba `Plan1` em CSV, para leitura rápida.

Ver o plano em [`../PLANO-PAINEL-v1.md`](../PLANO-PAINEL-v1.md) (bloco PARCELA)
